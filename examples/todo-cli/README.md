# todo-cli — a practice project

A tiny to-do list for the command line, used in the README's "Your first hour"
walk-through. It is small on purpose: you can read all of it in five minutes.

- `todo.py` — the program: `add`, `list` and `done`, saved to `todos.json`.
- `test_todo.py` — its tests; each names the requirement it proves.
- `specs/todo/requirements.md` — what it must do, one numbered sentence each.
- `Makefile` — `make check` and `make test`, the two commands the gates run.

Copy this folder somewhere else before you practise on it, never edit it here.
